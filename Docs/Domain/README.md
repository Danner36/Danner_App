# Domain

Current Guardians, Patriots, Cyclones, and parent-guided YouTube TV behavior.

## Documents

- [Guardians.md](Guardians.md) defines MLB data, today's countdown, remaining-game filtering, local-time formatting, and the GitHub-hosted approved playback list.
- [Patriots.md](Patriots.md) defines ESPN NFL leftover games, Eastern official dates, the regular-season record, and `patriots_streams.json` matching.
- [Cyclones.md](Cyclones.md) defines ESPN NCAA leftover football and basketball, Chicago official dates, three records, required `sport` matching, and elimination status.
- [Playback.md](Playback.md) defines offline map selection, saved destinations, WebView geolocation injection, and the shared four-step flow.
