# Domain

Current team-screen, league, streams, and parent-guided YouTube TV behavior.

## Documents

- [Hub.md](Hub.md) defines the hub grid, tile actions, the team picker, on-phone storage, and preset seeding.
- [TeamScreen.md](TeamScreen.md) defines the one team-screen engine: featured games, the card, win chance, the schedule, and refresh.
- [Leagues/MLB.md](Leagues/MLB.md) defines the statsapi adapter, with the Guardians as the worked example.
- [Leagues/NFL.md](Leagues/NFL.md) defines the ESPN NFL adapter, with the Patriots as the worked example.
- [Leagues/NCAA.md](Leagues/NCAA.md) defines the ESPN college adapters, per-sport records, per-game cards and postseason status, with the Cyclones as the worked example.
- [Streams.md](Streams.md) defines streams files, the fetch chain, the match rule, Get video, and playback kinds.
- [BasketballBoard.md](BasketballBoard.md) defines the basketball arena board: its cells, lineup replay and fallbacks, capability flags, foul rules, polling, layout, and states.
- [Playback.md](Playback.md) defines offline map selection, saved destinations, WebView geolocation injection, and the shared four-step flow.
