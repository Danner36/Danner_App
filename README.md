# Danner Apps

A cross-platform Expo app for Android and iPhone used by the Danner family. Its hub shows the teams chosen on each phone, then YouTube TV (TV Location), then `+` to add a team.

- `app/` is the Expo project.
- `catalog/` is the team catalog, and `streams/` holds each team's playback list.
- `scripts/stream-pipeline/` and `workers/team-worker/` serve Get video.
- `Docs/README.md` lists the sources of truth. `AI_Framework/AI_RULES.md` is the first read for agents.
