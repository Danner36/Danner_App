# scripts

Repository tools that do not run on the phone.

- `espn-capture/` captures live Iowa State college basketball games from ESPN on a schedule (`ESPN live capture` workflow) and commits trimmed polls and `REPORT.md` under `tests/leagues/<adapter>/captures/<event>/`, at most 2 games per adapter.
- `iphone-harness/` is the Windows USB diagnostic harness for the family iPhone's SideStore signing chain (status, SideStore refresh history and real expiry, live log watch during a charger plug-in, screenshots, launch tests). Its `out/` folder is git-ignored because pulled device logs carry the Apple Account e-mail. See its README and `FINDINGS-2026-10-09.md`.
- `guardians-stream-pipeline/` extracts an approved player URL for the current Guardians, Patriots, or Cyclones game and publishes the matching root streams file. An MLB game with `startTimeTBD` stays outside that window until MLB publishes a start time or the game is live.
- Game selection matches the app's featured card and does not depend on the runner's time zone: a game in progress (never a canceled, postponed, or suspended one), else the first unfinished game starting inside `[now − postStartGraceMinutes, now + leadMinutes]`, else today's game on the module's official calendar (America/New_York for Guardians and Patriots, America/Chicago for Cyclones), including a pre-game delay carried past midnight. Each workflow also sets `TZ` to that zone. A Cyclones `Time TBA` game uses the America/New_York date of ESPN's placeholder time, as the app does.
- The listing link must contain every href needle. When more than one link matches, the opponent's name narrows them; `extract.requireOpponent: true` also demands it on a single match. A choice that stays ambiguous fails as `ambiguous_link` instead of guessing. URLs from the listing page itself are discarded once the game page loads.
- Before publishing, the new entry passes the same playable check the app applies, and an `http://` provider URL is upgraded to https. Publishing reads the file and its SHA from GitHub, applies the change to that copy, and writes it back with that SHA, retrying the whole cycle on a conflict. A replacement removes only this game's date and game number from older entries, keeps other valid sources for the game, prunes entries whose dates are all more than 7 days old, and keeps the guide text and inactive example. A resumed MLB game keeps MLB's official date, and its earlier entry is replaced.
- Each workflow validates its config secret with `node run.mjs --check-config` before installing packages: module, `github.streamsPath`, Cyclones sport needles, and `extract.baseUrl`. Only Guardians falls back to its own team needle and file. Logs print listing paths, never the listing host. Local `config.json` is gitignored. Guardians Actions read `GUARDIANS_STREAM_PIPELINE_CONFIG`. Patriots Actions read `PATRIOTS_STREAM_PIPELINE_CONFIG` and set `sport` to `nfl`. Cyclones Actions read `CYCLONES_STREAM_PIPELINE_CONFIG`, set `sport` to `cyclones`, and scope the featured game with `DISPATCH_SPORT`.
- Listing sources: when the `STREAM_PIPELINE_CONFIG` secret is set, its ordered `sources` replace `extract.baseUrl`, each tried in turn in a fresh browser context until one yields an entry the phone would accept (`lib/sources.mjs`, player table in `lib/extract/providers.mjs`). When the secret is empty, `extract.baseUrl` is the only source and the run uses none of the failover codes, budgets or step summary. The `Write listing sources` step runs before every step that can print a host, emits `::add-mask::` for every source URL, origin and host, and writes the file under `$RUNNER_TEMP`; a pipeline run also masks each redirect and game-page host as it appears, and `lib/redact.mjs` rewrites what the pipeline prints. Logs and the step summary name sources only as `source 2/3 (backup-1)`. The manual `source` input runs one source by its 1-based number.
