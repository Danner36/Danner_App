# espn-capture

Live ESPN capture of Iowa State (team 66) college basketball games, the data source for validating the basketball arena board (`Docs/Production/ModularTeams.md`, Phase 1c). `capture.mjs` needs Node 22 or newer and no packages.

- When it runs: workflow `ESPN live capture` (`.github/workflows/espn-capture.yml`) every 10 minutes from 15:00 to 06:59 UTC, and on `workflow_dispatch`.
- `find` reads the Iowa State schedule of `ncaa/mens-basketball` and `ncaa/womens-basketball` for the season of the America/Chicago date (July through December count toward the next year) and takes the first in-progress event. A captured event is never taken again, and an adapter with 2 captured events is skipped, so capturing stops after 2 games per adapter. Request and parse failures log one line and leave the run green.
- `capture` polls the event's site summary and Core `competitions/{id}/situation` every 60 s until the summary's state is `post` (halftime and breaks between periods stay `in`), `MAX_MINUTES` pass (default 180, 10 to 240), or 10 summary requests in a row fail; a failed Core request is recorded and polling goes on. Capture jobs for the same event share a concurrency group: one runs, the newest waits, and GitHub cancels older waiting runs. A waiting run exits at once when the event's captures directory is already on `main`.
- Output: every raw poll, gzipped, in artifact `espn-capture-<run id>` (14 days). Up to 30 polls are committed to `main` as `github-actions[bot]` under `tests/leagues/<adapter, "/" as "-">/captures/<event>/<poll>.json.gz`: the first in-progress poll, each change of status name, period, or detail phase (halftime, end of period, overtime), every 10th poll, and the last poll. Each keeps `header`, `format`, `boxscore`, `plays`, `timeouts`, any `situation`, the Core situation status and body, `capturedAt`, and `pollIndex`. `REPORT.md` beside them lists the keys seen and, per committed poll, status, play, substitution and foul counts, `active` and `starter` counts per team, and every timeout, foul, bonus and possession field.
- Manual run: Actions, `ESPN live capture`, Run workflow, with `adapter` (`auto` or one adapter), optional `event` (an ESPN event id in that schedule; captured in any state and past the 2-game limit), and `max_minutes`.
- Once the arena-board flags are set from these captures, the schedule can be turned off with Disable workflow on the workflow's Actions page.
- Tests: `node --test scripts/espn-capture/capture.test.mjs` (pure helpers, no network).
