# team-catalog

Builds, validates and refreshes the committed team catalog (`catalog/`) that the Worker allowlist, the pipeline and the app picker read, and probes ESPN and statsapi for it (`Docs/Production/ModularTeams.md`, Team catalog). Node 22.18 or newer, no packages. `board-flags.mjs` imports the Expo board parser and rules, so the probe and validate run from a full checkout. Pass `--disable-warning=MODULE_TYPELESS_PACKAGE_JSON` to hide Node's note about those TypeScript imports.

- `probe.mjs` writes `catalog/probe-report.json`: for each adapter, every check's HTTP status and latency, with network errors and shape errors (missing paths from `required-paths.json`) kept separate, the arena-board paths of each basketball summary (reported, not required), and `boardFlags`. A filtered run keeps the other adapters' last entries. Raw bodies go to `.probe-output/` (git-ignored; artifact `espn-probe-<run id>`). An empty current-season schedule passes; the most recent live or final event is searched for in the two earlier seasons.
- `build.mjs` writes `catalog/leagues.json` and `catalog/teams/<league>.json`. A guard failure writes nothing and exits 1: a list under 90% of its committed count, a missing, retired or wrong preset (`mlb-5`, `nfl-17`, `ncaa-66`), or an MLB team without a statsapi match. Entries are append-only: an entry that disappears from ESPN stays with `retired: true`, a sport that disappears stays in `sports` and is also listed in `retiredSports`, and only `remove` in `catalog/overrides.json` deletes an entry. `pickable` is sticky: it turns on when the adapter's probe passes and `tests/leagues/<adapter>/` holds fixtures, and the build never turns it off.
- `validate.mjs` checks the leagues document, every team entry, the preset and nickname guards, `catalog/overrides.json`, the report's network and shape separation, the append-only rule against `--prior` (the catalog before the build), and `board-flags.mjs`: a capability flag on in `app/leagues/espn/basketballRules.ts` must be backed by the newest committed live capture (`tests/leagues/<adapter>/captures/`), every flag is off when none exists, and a flag the capture would allow but the app has off is reported in `boardFlags` only.
- ESPN data: `/teams?limit=1000` lists; the football list holds Division II and III programs, so only schools in the FBS and FCS standings (`/apis/v2/.../standings?group=80,81&level=3`) count as football schools. The basketball lists are Division I. A school's `conference` is its basketball conference's `shortName` from the standings tree, else football's.
- `live-capture.mjs` has `find` and `capture`: `find` takes the preset team's in-progress game on the adapter's schedule (a named adapter falls back to the first in-progress game on the league scoreboard), and `capture` polls the summary and Core situation every 60 s until the game ends, `MAX_MINUTES` pass (default 180, 10 to 240), or 10 summary requests in a row fail. Each adapter is captured at most 2 games unless an event is dispatched. A trimmed selection of up to 30 polls and `REPORT.md` are committed under `tests/leagues/<adapter>/captures/<event>/`; every raw poll is uploaded with them in artifact `espn-live-<run id>-<event>` (14 days).
- `issue.mjs` opens one GitHub issue for a failing probe or a failed build, unless one is already open.

Workflow `Team catalog` (`.github/workflows/team-catalog.yml`):

- Tuesdays 09:23 UTC or Run workflow (inputs `leagues`, `live_capture` empty): `probe` (`contents: read`) then `build` (`contents: write`, `issues: write`), which runs `build.mjs` and `validate.mjs` and commits `catalog/` with message `catalog: refresh team list.`, rebasing and retrying up to 3 times.
- Game hours (every 10 minutes, 15:00 to 06:59 UTC) or Run workflow with `live_capture`: `live-find`, one read-only `live-capture` job per live game, then `live-commit`, the only job there with a write token, which commits the trimmed capture. The scheduled path stays idle while `scripts/espn-capture/capture.mjs` exists.
- Run workflow inputs: `leagues` (league or adapter keys, comma separated), `live_capture` (`auto` for both NCAA basketball adapters, or one adapter), `live_event` (optional ESPN event id; captured in any state and past the 2-game limit), `live_max_minutes`.

Tests: `node --disable-warning=MODULE_TYPELESS_PACKAGE_JSON --test "scripts/team-catalog/test/*.test.mjs"` (fixtures only, no network).
