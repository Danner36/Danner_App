# tests

Repository-only validation harnesses. Files under this directory are not imported by the Expo application and are not packaged into Android or iPhone builds.

## Harnesses

- `guardians/` simulates today, video-ready, delayed, live, and Final recap Cleveland Guardians states and supplies HTTPS direct-media, local HTTP direct-media, YouTube, popup/redirect safety checks, a page-reported HLS player, and a moving capture-pattern page to a development build. `run-snapshot.mjs` checks featured-card selection, MLB `startTimeTBD`, Warmup, rain-delay status, postponed makeups, suspended games, and the streams-file cap, with its time zone pinned. `run-cast-discovery.mjs` checks the page-reported Cast URL gate, the per-page message nonce, the MP4-then-HLS upgrade through the real injection, relay kinds and failure messages, relay origin validation, live relay stream type, and relay variant selection. `run-cast-web.mjs` opens that player on a device and asserts Cast loads only the phone's token relay URL and plays. The two converter harnesses moved to `reference/screen-capture-hls/tests/` with the pipeline they exercise.
- `patriots/` simulates today, video-ready, delayed, live, and Final recap New England Patriots states plus Get video on port 8112. `run-snapshot.mjs` checks featured-card selection, regular-season record, Eastern official dates, `Time TBA` dates across time zones, ESPN game-state mapping, and season-type tagging. Get video requires Play in the same session.
- `cyclones/` simulates today, video-ready, delayed, live, and Final recap Iowa State states plus Get video on port 8113. `run-snapshot.mjs` checks featured-card selection across sports, regular-season records, Chicago official dates, Eastern `Time TBA` dates, postseason statuses, neutral sites, and the streams-file cap in any machine time zone. Get video requires Play in the same session.
- `offline-map/` checks pin coordinates, city labels (including suburbs next to major cities), and offline city search against the bundled Census place list, and checks that the selection code shipped inside `app/assets/offline-us-map.html` agrees with `offlineMapSelection.ts`, without opening YouTube.
- `provisioning-warning/` verifies the hidden, 48-hour, hourly, final-hour, and expired iPhone signing-warning text without adding a test control to the app.
- `app-update/` verifies the strict release-tag parser, version compare, the `app.config.js` version bake, the release workflow's tag regex, manifest parse, trusted download URLs, signing-warning suppression, SideStore install URL encoding, and the release manifest writer.
